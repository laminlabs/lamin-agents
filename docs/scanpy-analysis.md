# Scanpy analysis

Agentic re-implementation of the classic [PBMC3k Scanpy tutorial](https://docs.lamin.ai/pbmc3k): QC, clustering, marker discovery, and cell-type annotation — with cutoffs and labels chosen from the data, not hard-coded from the docs.

**Instance:** [laminlabs/lamindata](https://lamin.ai/laminlabs/lamindata) · **Branch:** [scanpy-k-dense](https://lamin.ai/laminlabs/lamindata/branch/g9twcoxHhXlA) · **Agent run:** [Claude Code](https://lamin.ai/laminlabs/lamindata/transform/SnfuhjObaAKR0000/Tvs6zyplFnAJx1oj?branch=scanpy-k-dense)

Write-up: [analysis report](https://lamin.ai/laminlabs/lamindata/artifact/4MP8fmwelTNty52u0000?branch=scanpy-k-dense)
